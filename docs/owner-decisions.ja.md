# オーナーの決定事項 記入シート

設計書（docs/design.ja.md）19章「オーナーが決定すべき事項」のうち、まだ決まっていないものを決めて Claude に伝えるためのシートです。

## 書き方

- 選ぶものの `[ ]` を `[x]` にします。複数選べる項目には「（複数可）」と書いてあります。
- 「暫定案」は、設計書に今書いてある案です。暫定案のままでよければ、暫定案に `[x]` を付けるだけで構いません。
- まだ決められない項目は「保留」に `[x]` を付けます。保留の理由や、決めるために知りたいことがあれば「メモ」に書いてください。
- 「メモ」には、条件、理由、Claude への質問など、何を書いても構いません。
- 全部の項目を一度に埋める必要はありません。埋めたところまでで渡してください。

決定済みの D-02（ライセンス）、D-05（最低対応バージョン）、D-12（公開先）、D-14（GitHub のリポジトリ名）はこのシートに入れていません。見直したい場合は、末尾の「その他」に書いてください。
