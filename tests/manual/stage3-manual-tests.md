# 段階3 の手動テスト：M-13 と日本語の訳の確認

設計書 16.3節の M-13（表示言語）と、16.1節の「翻訳の確認」（日本語はオーナーが確認する）の手順。

| 項目             | 内容                                                                      |
| ---------------- | ------------------------------------------------------------------------- |
| 対象             | `publish/io.github.akiratamcat.dg-plantuml.jpl`（`npm run dist` で作る）  |
| 環境             | Joplin の最新の安定版（Windows）                                          |
| テスト用のノート | [mvp-note.md](mvp-note.md)（9 は構文エラー、10 は標準ライブラリのエラー） |
| 所要時間         | M-13 が約 15分、日本語の訳の確認が約 15分                                 |

Joplin の表示言語は、設定 → 全般（アプリケーション）→「言語」で変える。変えると Joplin の再起動を求められるので、再起動する。プラグインは、起動したときの表示言語を使う（設計書 10.3節）。

---

## M-13 表示言語

### A. 日本語

1. Joplin の表示言語を「日本語」にして再起動する。
2. **確認**：設定 → プラグイン → dg-plantuml の画面が日本語になる（「図のテーマ」「明るいテーマのときのスタイル」など）。選択肢（「PlantUML 標準（明るい配色、既定）」など）と説明文も日本語になる。詳細設定の項目も日本語になる。
3. mvp-note のノートを開く。
   - **確認**：9 のエラーボックスの見出しが「PlantUML のエラー」、メッセージが「3 行目: Syntax Error? …」になる。メッセージの後半（Syntax Error? …）は PlantUML のエンジンの英語のままでよい。
   - **確認**：10 のエラーボックスも「PlantUML のエラー」「1 行目: cannot include …」になる。
4. 「Maximum source length」（日本語では「ソースの最大文字数」）を 1000 にして、[stage2-note.md](stage2-note.md) の 6 を開く。
   - **確認**：エラーボックスが「図が大きすぎます。」「ソースは 1290 文字です。上限は 1000 文字です。」になる。
   - 確認したら 100000 に戻す。

### B. 英語

1. 表示言語を「English」にして再起動する。
2. **確認**：設定画面とエラーボックスが英語になる（「Diagram theme」「PlantUML error」「Line 3: …」）。

### C. 中国語

1. 表示言語を「中文 (简体)」にして再起動する。
2. **確認**：設定画面とエラーボックスが中国語（簡体字）になる（「图表主题」「PlantUML 错误」「第 3 行：…」）。文字化けがない。
3. （できれば）「中文 (繁體)」にして、繁体字（「圖表主題」「PlantUML 錯誤」）になることも確かめる。

### D. 翻訳がない言語

1. 表示言語を、翻訳を用意していない言語（例：Nederlands、Polski）にして再起動する。
2. **確認**：設定画面とエラーボックスが英語になる。

後片付け：表示言語を日本語に戻して再起動する。
